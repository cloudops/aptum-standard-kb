The Aptum Portal home page is the default page a user is presented with when logging into the system.

![Screenshot of the Aptum Portal home page, with numbered dots highlighting features of interest](img/general-cmc-ui-home-en.png)

1.  **Workspace**

    The workspace is the main section of all Aptum Portal screens. The items that are visible in the workspace are determined by the context of where you are in the system. For example, in the home page listed here, you can find the services map, the quick access panel, as well as summaries of system health and recent activity.

2.  **Main navigation buttons**

    The main navigation buttons of any Aptum Portal screen. This where you can navigate to all of the major features of the system, including service connections, reporting, activity logs, and administration.

3.  **Organization picker**

    Aptum Portal is a multi-tenant platform. Use the organization picker to navigate between the organizations and sub-organizations you have access to.

4.  **Help, notification, and User Settings menus**

    The top corner of any CloudOps screen contains three items: the help menu, the notifications menu, and the User Settings menu.
